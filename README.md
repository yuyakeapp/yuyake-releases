# Yuyake

Yuyake is a Mac app for **live and photo-slideshow wallpapers**. Pick a scene and it plays on your **desktop** and, if you want, the **lock screen**. Import clips, create a slideshow from selected image files, or browse stock video. There is no account, personal media stays on your Mac, and the app contains no advertising or behavioral analytics.

## Versioning

Yuyake is currently shared with a small feedback group. These builds use
`0.0.x`, starting at `0.0.1`. The patch number increases with each feedback
release. `1.0.0` is reserved for the final, production-ready MVP.

## Install

1. Open the DMG and drag **Yuyake** to Applications.
2. Open Yuyake from Applications. Signed, notarized builds open normally. If macOS blocks it, right-click → Open once.
3. For lock screen video: **System Settings → Privacy & Security → Full Disk Access** → turn on Yuyake.

Requires macOS 14 (Sonoma) or later.

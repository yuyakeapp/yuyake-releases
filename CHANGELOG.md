# Changelog

Release notes for every published Yuyake build. Each entry matches a [GitHub Release](https://github.com/yuyakeapp/yuyake-releases/releases).

## [0.0.2](https://github.com/yuyakeapp/yuyake-releases/releases/tag/v0.0.2) — 2026-10-10

### Added

- Quitting or updating Yuyake leaves your macOS wallpaper as it was, and Settings, Storage has a "Restore macOS wallpaper" button
- Help menu: Send Feedback and Copy Diagnostics, with nothing sent unless you choose to

### Changed

- Privacy text now lists every connection Yuyake makes
- Weather comes only from Open-Meteo; Apple WeatherKit is gone
- Rotation, schedules and collections have no limits, and the unused Pro and StoreKit code is removed
